# 作者否决对照样例（规程 §6.3 第 3 部分、§7.3）

七个样例供作者在冒烟第 3 部分对照 V1、V2 的判断方法。**这里写的是预期判断，不由脚本判定**；作者按 §7.3 的条件自己判断后与下表对照，不一致时先回到 §7.3 的条文。

共同点：
- 都是完整的 `dot4sat` 模块（ANSI 端口，L = 2：第 1 级寄存四个乘积 `r0..r3` 和 valid，第 2 级寄存饱和结果和 `out_valid`）。
- 都能通过合同门槛 G1–G7（`test_gate.test_veto_samples_reach_author_review`，`DECLARED_L = 2`），所以会进入作者审查；V1、V2 不是门槛规则。
- 只用来练习判断，不运行 `grade.py`，不声称功能正确。
- valid 流水线有两级：第 1 级（`v1`，样例 6 为反相编码的 `invalid1`）和第 2 级（`out_valid`）。V2 要求每一级在 `rst = 1` 的时钟沿，按代码的赋值优先级，下一状态恒为"无交易"。

| 样例 | V1 预期 | V2 预期 | 理由（行号为该文件中的行） |
|---|---|---|---|
| `s1_v1_default_then_override.v` | 不命中 | 不命中 | 组合块第 20 行先给 `sat` 默认值，第 21–22 行在分支中覆盖；块首默认赋值算作对整条路径的赋值，没有一条路径漏赋值。V2：第 26–28 行 `rst` 时清 `v1` 和 `out_valid`（本样例的数据寄存器也复位，与 V1 判断无关） |
| `s2_v1_missing_assignment.v` | **命中** | 不命中 | 组合块第 19–22 行：`sum` 在饱和范围内时（两个条件都不成立，是可达路径）`sat` 没有被赋值，会保持旧值，即锁存器。依据合同第 2 节。V2 同样例 1 |
| `s3_v1_unreachable_branch.v` | 不命中 | 不命中 | 第 21 行 `if (SAT_ON)` 的隐含 else 分支中 `sat` 没有赋值，但 `SAT_ON` 是第 19 行的 `localparam`，恒为 1，该分支在常量条件下不可达，不算；可达路径上第 22 行有默认赋值。V2 同样例 1 |
| `s4_v2_data_not_reset.v` | 不命中 | 不命中 | 数据寄存器 `r0..r3`、`out_data`（第 34–40 行的时序块）没有复位，合同第 2.4 节允许；两级 valid 在第 26–28 行被清空。组合块同样例 1 |
| `s5_v2_equivalent_boolean.v` | 不命中 | 不命中 | 第 26 行 `v1 <= in_valid & ~rst`、第 27 行 `out_valid <= v1 & ~rst`：`rst = 1` 时两级的下一状态都是 0（无交易），只是写法不是 `if (rst)`，等价的布尔写法不命中 |
| `s6_v2_inverted_valid.v` | 不命中 | 不命中 | 第 1 级反相编码：`invalid1 = 1` 表示无交易。第 26 行 `invalid1 <= rst \| ~in_valid`，`rst = 1` 时下一状态为 1 = 无交易；第 27 行 `out_valid <= ~rst & ~invalid1`，`rst = 1` 时为 0 = 无交易。看的是逻辑有效状态，不是比特值，所以不命中 |
| `s7_v2_stage_not_cleared.v` | 不命中 | **命中** | 第 26 行 `v1 <= in_valid` 不受 `rst` 影响：`rst = 1` 且 `in_valid = 1` 的时钟沿，第 1 级的下一状态是"有交易"。第 27–28 行只清了 `out_valid`。依据合同第 2.3 节"复位优先于接收新交易并清空在途 valid" |
