# 接口时序的意图说明（intent.md）

- 全部 130 个非时钟输入（`in_a[63:0]`、`in_b[63:0]`、`in_valid`、`rst`）来自同一个上游时钟域的寄存器输出，相对 `clk` 上升沿最晚在 0.2·T 到达（max），最早在 0 到达（min），rise 和 fall 相同，由 `sky130_fd_sc_hd__buf_2` 驱动；T = 27.91 ns，所以 max = 5.5820 ns。
- 全部 33 个输出相对 `clk` 上升沿，外部要求 max = 0.2·T、min = 0，每位负载 C_load = 0.0024 pF。
- 这份意图说明表达的是要求。它不能证明某次运行实际施加了这些约束；是否施加，只能由该次运行的展开约束和覆盖检查证明。
